##  PYTHON SHOPPING CART PROGRAM

A beginner-friendly shopping cart program built with Python. This application allows users to enter food items, record their prices, view their cart, and calculate the total cost of their purchases.

##  FEATURES

- Add food items and their prices.
- Display all items in the cart.
- Calculate the total cost of purchases.
- Enter `q` to quit the program.

##  TECHNOLOGIES USED

- Python
- PyCharm

##  HOW THE PROGRAM WORKS

1. Enter the name of a food item.
2. Enter its price when prompted.
3. Continue adding items.
4. Enter `q` when you are finished.
5. View your cart and the total cost.

##  HOW TO RUN

1. Clone this repository:

   ```bash
   git clone https://github.com/abdinasir703/PYTHON-SHOOPING-CART-PROGRAM.git
   ```

2. Open the project in PyCharm.
3. Run the Python file.

**Requirement:** Python 3 installed on your computer.
